# GFS / EC 模型切换设计

## 范围
为台风路径所有已有数值产品恢复底部 GFS / EC 来源切换器。默认 GFS；只使用原版公开接口，不制造或改写预报日期。

## 数据源
- GFS：`https://datacenter.istrongcloud.com/data/gfsimgv4/06_time_{type}.json`
- EC：`https://datacenter.istrongcloud.com/data/ecmwfv4/06_time_{type}.json`
- 帧 JSON 与 PNG 均使用时间清单返回的 `base_url`、`url`、`img_url`。

## 状态与行为
- 数值图层开启后显示模型切换器，关闭后隐藏。
- 默认模型为 GFS；各数值产品分别记忆本次页面生命周期内的选择。
- 切换模型时使旧请求失效，移除旧图层和帧缓存，重新读取时间清单并从合适帧开始。
- EC 接口 404、空列表或首帧资源不可用时禁用 EC，并保持或回退 GFS。
- EC 时间清单可用但陈旧时允许查看，同时在模型控件和图层提示中显示实际日期；不得称作实时或当前预报。
- 不影响数值产品之间原有 group 4 互斥规则。

## UI
- 位于时间轴正上方居中，白色半透明胶囊。
- GFS 与 EC 为两个等宽分段；选中项使用橙色强调填充。
- EC 陈旧时显示实际起报月日；不可用时禁用并降低透明度。
- 紧邻信息按钮以简短提示解释模型与日期状态。

## 验收
- 风场、浪场、温度、水汽、500hPa、海平面气压均显示入口。
- GFS 请求 `gfsimgv4`；EC 请求 `ecmwfv4`，切换后 Canvas、标题、时间轴与日期同步变化。
- EC 旧数据有明确日期；不存在的数据不可点击且不会破坏当前 GFS 图层。
- 快速切换不会被旧异步请求覆盖；关闭图层后控件和旧 Canvas 清理。
