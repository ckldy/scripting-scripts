# 台风路径可靠性与安全修复设计

日期：2026-08-11  
状态：已获方案 A 方向确认，待本规格复核后实施

## 目标

在不扩展地图功能、不新增依赖、不自动发布的前提下，修复审计发现的密钥暴露、Widget 图文不同步、弱网刷新竞争、缓存发布不完整和用户错误信息泄漏问题，并完成低风险资源整理与发布状态核验。

## 方案选择

- **采用 A（完整可靠性修复）**：一次覆盖安全、缓存一致性、刷新可靠性、错误提示和资源整理。
- 不采用仅靠延长刷新间隔或展示旧图的方案：它们不能保证 Widget 的文字和地图来自同一份台风数据。
- 不新增数据库、第三方库或后台服务：使用现有 App Group 文件、Keychain、Scripting `fetch` 与文件 API。

## 设计

### 1. 高德 Key 边界

`amapKeyStatus()` 只返回 `configured`、`masked` 与可选更新时间，绝不返回完整 Key。`index.tsx` 的 WebView bridge 继续从原生内存读取 Key 完成验证和制图；Web 页面不再预填完整 Key。已配置有效时仍保持只读状态；清除后方可重新输入。

App Group 仍保留 Key 是既有 Widget/主程序跨上下文的兼容通道，本次不改变其存储格式；不在日志、错误或 bridge 响应中输出完整 Key。

### 2. Widget 地图代次 manifest

在 App Group 增加 `map-<id>.json`。每一条记录至少包含：台风 ID、末点时间、数据更新时间、PNG 文件名和生成时间。

渲染流程：先把新 PNG 写入临时文件；成功后发布最终 PNG；最后写入 manifest。Widget 仅当 manifest 的 ID、末点时间与当前 `state.json` 台风末点相同，且 PNG 存在时才展示地图。任何不匹配都展示“地图缓存生成中”，不展示旧地图。

这是最小的一致性协议：不修改 `state.json` 格式，不为每次选择切换重绘地图；选择变化仍可复用同一台风、同一末点的地图。

### 3. 刷新可靠性

给 Widget 数据请求和高德 Key 验证增加统一的有限超时包装。`index.tsx` 中的 Widget 缓存刷新改为进程内单飞：同一时间已有刷新时复用同一个 Promise，避免连续打开主程序造成并行下载/渲染。

每次 `loadWidgetData()` 成功生成本轮 `updatedAt`；渲染调用把该值写入 manifest。没有新增持久锁：单个脚本运行期的任务竞争由单飞解决；跨进程情况通过 manifest 的末点时间校验安全降级为“生成中”。

### 4. 缓存写入和错误反馈

`state.json` 保持现有结构并以临时文件替换，减少半写文件风险。地图 PNG 也通过临时文件→最终文件→manifest 的顺序发布。对读缓存失败继续回退到旧缓存。

Widget 对外仅展示稳定文案“台风数据暂时无法更新，请稍后重试”；内部日志保留有限上下文，但不直接串接原始异常、URL 或 Key。

### 5. 前端资源整理

删除 `web/index.html` 中多余的 `</script>`。本轮改动的本地网页资源统一使用同一个发布查询版本号；不重构或拆分压缩的 `app.js`。

### 6. 发布核验

将本地 `script.json` 的版本与 Git 工作树、`dist/台风路径.zip`（如存在）和已记录发布版本 2.1.4 对比，形成明确状态：已发布、待打包或待推送。除非用户另行授权，不执行 Git 提交、打包上传或远端推送。

## 验收

1. `getAmapKeyStatus` 的响应和 `amapKeyStatus()` 均不含 `key` 字段。
2. 给定末点时间不一致的 manifest，Widget 不读取旧 PNG。
3. 同一运行期重复调用地图刷新只产生一个实际刷新任务。
4. 缓存写入有临时文件发布步骤，且 PNG 成功后才更新 manifest。
5. Widget 错误页不再直接显示 `String(error)`。
6. 修改文件通过 TypeScript diagnostics；Widget medium/large 预览成功；主程序能加载并展示页面（WebView 等待用户关闭造成的超时单独说明）。
7. 安全检查确认没有新硬编码 Key，且桥接/日志不传出 Key。

## 非目标与残余风险

- 不修改原版地图视觉和公开数据契约。
- 不迁移 App Group 中既有 Key 到仅 Keychain：Widget 扩展兼容性需要现有共享通道。
- 不做跨进程文件锁；manifest 校验可避免将不一致地图作为正确地图展示。
- 不自动发布 2.1.5 或新版本。
