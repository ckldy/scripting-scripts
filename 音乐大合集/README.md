> **作者 / 维护**：[vcncv](https://github.com/ckldy) ｜ **版本**：v1.0.0 ｜ **运行环境**：iOS Scripting App

一款专为 iOS Scripting 环境打造的高品质、多源聚合随身音乐播放器。结合本地静态服务与原生桥接，具备多音源曲库聚合搜索、无损音质自动降级、经典与沉浸双重播放舞台、窗口模式全自适应、纯净无下划线歌词滚动与后台保活播放等丰富特性。

## ✨ 核心特性

### 1. 多站源曲库聚合
- **五大平台原生桥接**：深度整合 QQ 音乐、网易云音乐、酷狗音乐、酷我音乐、咪咕音乐曲库。
- **突破 CORS 跨域限制**：通过 Scripting 本地 HttpServer 与推送模式 HTTP 桥，原生直连各平台高保真音频流与歌词服务。
- **自定义音源扩展**：支持在线导入或从本地导入音源 `.js` 扩展插件，多源自由管理与切源。

### 2. 播放舞台与全窗口自适应
- **经典卡片 / 沉浸海报双样式**：
  - *经典卡片*：拟真 Apple Music 经典卡片设计，封面高光阴影，背景随封面色阶动态漫射。
  - *沉浸海报*：顶部大封面自适应淡出，智能算法提取主色与副色，全景流光渐变。
- **多窗口完美自适应**：
  - 针对 iPadOS 台前调度（Stage Manager）、Split View 分屏以及悬浮窗口深度适配（采用 `100dvh` 可视高自适应算法）。
  - 在任何极限高度或小窗口模式下，**自由进度条、播放控制按键（上一首/播放/暂停/下一首/循环模式）与底部工具菜单始终完整可见、随手可点、绝不被遮挡**。

### 3. 纯净优雅的歌词体验
- **无下划线纯净排版**：高亮歌词文字干净醒目，深浅主题自适应高对比色调，彻底杜绝任何多余横线或合成层撕裂伪影。
- **毫秒级平滑垂直滚动**：当前句自下而上丝滑居中，并智能支持上下手势预览浏览与点击全屏歌词模式。
- **锁屏歌词轮播**：当前唱到的歌词与下一句轮流同步至锁屏与通知中心 Now Playing 界面，闭屏也能随时看词。

### 4. 四重个性化动感进度条
- **星轨（Orbit）**：正弦浪涌波形 + 独立高亮红点滑块，流畅跟随音乐律动。
- **心率（Wave）**：36 列交错跳动的动态心率柱状脉冲，已播与未播段清晰对比。
- **光轨（Glow）**：呼吸光晕流光轨道，前沿高光流动闪烁。
- **普通（Bar）**：极简细轨，轻量沉稳。

### 5. 音质多档调节与自动降级
- 支持标准（128k）、较高（192k）、高品（320k）、无损（FLAC）、Hi-Res、母带（Master / AI00）等多档音质自由选择。
- **智能降级机制**：某源无特定高码率或流媒体加载失败时，自动平滑回退至下一档可用音质，确保连续播放不中断。

### 6. 原生后台保活与系统媒体联动
- 结合 `Script.enableMinimize()` 与 iOS 原生音频会话，后台运行及锁屏时持续流畅播放不杀进程。
- 完整对接系统 `MediaSession`，灵动岛、锁屏控制中心、蓝牙耳机线控均能精准同步歌名、歌手、封面与播放状态。

